Recon

Evidence-led reverse engineering for apps.

An agent-facing workbench for investigating reference applications, starting with native, Electron, and web apps on macOS. The aim is to turn controlled observations into behavioral specifications that can be checked against an independent implementation.

Read the vision

The intended investigation loop

  1. Discover

    Choose a behavior and record what remains unknown.

  2. Experiment

    Vary one condition against a recorded baseline.

  3. Specify

    State the behavior the evidence supports.

  4. Compare

    Check another implementation against the reference and keep differences visible.
