Recon

Evidence-led reverse engineering for apps.

An agent-facing workbench for understanding software through binaries, runtime objects, native views, web documents and styles, network activity, resources, and platform APIs, with macOS as the first host.

Available today: macOS app discovery, metadata, and launch; window listing, accessibility trees, and screenshots; and native AppKit view, layer, layout, and font inspection through an explicit session. Other inspectors and the behavioral investigation loop remain future work.

A planned workflow: behavioral investigation

  1. Discover

    Choose a behavior and record what remains unknown.

  2. Experiment

    Vary one condition against a recorded baseline.

  3. Specify

    State the behavior the evidence supports.

  4. Compare

    Check another implementation against the reference and keep differences visible.
